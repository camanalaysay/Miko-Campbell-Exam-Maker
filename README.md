# Campbell Exam Builder

Practice exam generator for Campbell-Walsh-Wein Urology, prepared for Miko Bolong, MD.

Open `index.html` in a browser. Pick the number of questions, the sections or chapters to cover, and the difficulty levels. The page then builds two PDFs: the exam, and the answer key with a rationale for every question and a note on why each other option is wrong.

- Question bank: 8,020 items across all 162 chapters (50 per chapter; 30 for chapters 7, 9, 88 and 105).
- Same exam code + same settings = the same exam.
- An internet connection is needed for the PDF library and fonts.
- Use **Add picture** to place your own image on the page and on page one of both PDFs.

The answer key and rationales are embedded in the page, so this is for practice and self-study only, not for graded or proctored exams.
